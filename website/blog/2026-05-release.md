## 核心更新

### 📖 RAG 检索增强

- 支持多种文档格式（PDF、Word、Markdown、TXT）
- 向量化过程自动化
- 相似度检索算法优化
- 支持重排序（Re-ranking）

### 🛠️ 多工具支持

MGAgent Agent 现已支持多种工具：

- **计算器工具**：自然语言数学计算
- **数据库查询工具**：自然语言转 SQL
- **Web 搜索工具**：实时信息检索
- **代码执行工具**：Python 代码沙箱

### 🔄 工作流引擎

- 多步骤任务自动规划
- 工具调用链优化
- 错误自动重试
- 支持人工干预

## 功能改进

- 对话上下文记忆增强
- 流式响应体验优化
- 知识库批量导入
- 对话历史搜索功能

## 使用示例

```python
# 初始化 Agent
agent = MGAgent()

# 自动选择工具
response = agent.chat("帮我查询上个月的销售数据并计算增长率")

# Agent 会自动：
# 1. 识别意图 -> 数据查询 + 计算
# 2. 调用数据库工具获取数据
# 3. 调用计算器工具分析
# 4. 生成自然语言报告
```
